# Checkpoint — 상태 외재화 & 세션 리셋 계약 (스택 중립)

> 세션을 오래 살리는 대신 **짧게 살리고 상태를 파일로 넘긴다.** 컨텍스트는 관리하는 자원이다.
> 상태 영속화(파일)와 컨텍스트 위생(리셋)은 **별개 축** — 파일에 잘 적어도 오염된 라이브 세션은 안 나아진다.

## 1. 언제 — **수치로 판단한다** (주관 신호는 늦다)

⚠️ **먼저 — 나는 내 컨텍스트 사용률을 못 본다.** 그래서 "50% 넘으면"류 임계는 **발동하지 않는다**
(실측 2026-08-03: 이 스킬 호출 **0회**. 임계를 관측 불가능한 값으로 써놨던 게 원인이다).
**관측 가능한 이벤트로 센다.**

**아래 중 하나라도 해당하면 청크 중간이라도 먼저 제안한다:**

| 관측 가능한 신호 | 왜 이것이 대리 지표인가 |
|---|---|
| **커밋 2회** 이상 | 한 덩어리 일이 끝났다는 뜻 |
| **서브에이전트 3회** 이상 스폰 | 회당 80~160k가 컨텍스트에 얹힌다 |
| **스크린샷 3장** 이상 | 1장 ≈1.4k가 **세션 끝까지 매 턴 재투입**된다 |
| **주제 전환** (A 기능 끝 → B 시작) | 앞 주제 컨텍스트가 순수 비용으로 남는다 |
| **같은 파일 3회 이상 재열람** | 컨텍스트가 흐려졌다는 신호 |

사용자가 사용률을 볼 수 있는 환경이면 **50% / 400k**를 함께 쓴다 — 다만 그건 **사용자가 판단하는 값**이다.

> **주관 신호("판단이 흐려지는 징후")를 기다리지 마라 — 그 시점엔 이미 늦다.**
> 실측(2026-07-31, 세션 로그 4,469턴): 컨텍스트가 세션 내내 **한 번도 압축되지 않고**
> `90k → 728k`까지 자랐다. **후반 턴이 초반보다 7~8배 비싸고**, 989턴 세션 하나가 385M 캐시읽기를 썼다.
> 가중 비용의 **72%가 캐시읽기** — 새로 만든 내용이 아니라 **이미 있는 컨텍스트의 재투입**이다(추정: 요금 가중치 기준).
> **세션을 안 끊는 것이 단일 최대 원인이다.** 400k→150k대 유지 시 캐시읽기 60~70% 절감(상한 추정).

- 위 신호와 무관하게, 작업 청크(기능 1개·검증 1라운드) 완료 시에도 한다.
- ⛔ **사용자가 요청할 때까지 기다리지 마라.** 이 스킬이 0회였던 이유는 아무도 부르지 않아서다 —
  **먼저 한 줄로 제안하는 것**이 이 스킬의 진입점이다.
- 한 번 제안했다가 거절당하면 **그 세션에선 다시 묻지 않는다**(잔소리 금지).
- 늦은 신호(참고): 같은 파일 반복 오독·앞서 정한 결정 망각·검증 출력 누적.
- ⚠️ **재시작에도 비용이 든다**(resume·CLAUDE.md 재적재 + 재탐색). 그래도 순이득이 크지만, 5분마다 끊지는 마라.

## 2. resume.md 갱신 (핵심)
`.tasks/resume.md`의 각 섹션을 **현재 상태로 덮어쓴다**(append 아님, 최신 스냅샷만). 히스토리는 넣지 않는다.
- **"다음 1수"**: `iterate`를 돌렸으면 **그 결과를 옮겨 담는다**(여기서 재도출하지 않음). 역할 구분 — `iterate`=진척 분석(→ iterate-log 히스토리), `checkpoint`=리셋용 스냅샷(→ resume 덮어쓰기).
- **"불변식/함정"**: **이 세션에서 발견한 것만**. 영구 규칙(예: "인증은 서버 판단")은 resume가 아니라 conventions/CLAUDE.md/메모리로 **래칫**한다.

## 3. 아카이브 분리
완료 항목은 `done.md`, 진척 로그는 `iterate-log.md`로 이동. resume.md엔 남기지 않는다(짧게 유지).

## 4. 리셋 권고
사용자에게 안내: *"resume.md에 상태를 저장했습니다. `/clear` 후 '이 프로젝트 resume.md 읽고 이어가줘'로 새 세션에서 이어가면 컨텍스트가 깨끗합니다."*
> Claude Code의 자동 compaction보다 이 **큐레이션 리셋**이 더 신뢰도 높다(요약이 뭉개는 것 방지). 완전 자동화는 hook 필요 — 현재는 권고까지.

## 5. 재시작 규약
새 세션의 첫 행동은 `resume.md` **하나만** 읽고 그로부터 재구성하는 것. 옛 세션의 인라인 기억에 의존 금지.
